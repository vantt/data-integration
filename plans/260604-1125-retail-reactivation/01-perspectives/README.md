## Cách thêm lens mới

1. Tạo file mới trong folder này (kebab-case, tên mô tả lens).
2. Frontmatter: `stage: 1`, `status: living`, `source: ...`.
3. Ghi rõ lens dẫn tới investigation nào ở [02-understand](../02-understand/) hoặc opportunity nào ở [04-opportunities](../04-opportunities/) — dùng dòng `→ **Spawned:**` sau mỗi lens.
