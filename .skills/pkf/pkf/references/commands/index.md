# Commands

One concept per subcommand. Each links to the [concepts](../concepts/index.md) it depends on.

- [init](init.md) — one-time scaffold
- [issue](issue.md) — file + clarify + plan
- [research](research.md) — bounded research loop: feeds an issue, or standalone enriches docs/
- [work](work.md) — pick + load context + execute a planned issue, verify DoD
- [status](status.md) — dashboard (read-only)
- [query](query.md) — answer a question by navigating the bundle (read-only)
- [update](update.md) — reconcile a named drift, or auto-extract an insight/decision when untargeted
- [validate](validate.md) — conformance + lint check
- [viz](viz.md) — regenerate the graph visualization
